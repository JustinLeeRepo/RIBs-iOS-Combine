# RIBs Tutorial 1: Creating a RIB

This project is the starting point for [tutorial 1](https://github.com/uber/RIBs/wiki/iOS-Tutorial-1) that will get you aquatinted with the RIBs architecture.

### Getting started

Install tooling, unless you've done so already:

```
<RIBs path>/tooling/install-xcode-template.sh
```

Then, open `<RIBs path>/tutorials/tutorial1/TicTacToe.xcodeproj`. Xcode fetches the package dependencies on its own: RIBs from this repository, and SnapKit. There is nothing else to install.

Follow the steps described in [tutorial 1](https://github.com/uber/RIBs/wiki/iOS-Tutorial-1) on the RIBs wiki. The wiki was written for the RxSwift version of RIBs. The [README](../../README.md#documentation) at the root of this repository lists the Combine equivalents used here.
